# ArtFlashCard

중등미술 임용고시 대비 웹 플래시카드. 서버·로그인 없이 동작하는 정적 페이지입니다.

## 특징

- **데이터**: `data/cards.csv` 한 파일만 수정하면 카드가 갱신됩니다
- **학습 기록**: 브라우저 localStorage에 저장 (로그인 불필요, 기기별로 분리됨)
- **범위 선택**: 과목(단일) → 유형·시대·태그·중요도(복수, 기본 전체 선택)
- **3가지 모드**: 설명 제시(기본) / 표제어 제시 / 이미지 제시
- **자가 채점**: 답 공개 후 ⭕/❌ 로 채점 → 과목·유형·태그별 정답률 집계
- **가중 출제**: 맞힌 카드는 출제 빈도가 절반씩 줄고 시간이 지나면 다시 회복
- **오답 노트**: 틀린 카드만 범위와 무관하게 몰아서 복습. 맞히면 목록에서 해제
- **관련 항목**: 뒷면에서 같은 갈래 형제(태그 자동)와 관계(`data/links.csv`)를 펼쳐 볼 수 있음
- **글자 크기 4단계**: 모바일 가독성을 위해 조절 가능하며 선택값이 유지됨

## 데이터 스키마 (`data/cards.csv`)

| 컬럼 | 설명 |
|---|---|
| id | 고유 번호. **재부여 금지** — 학습 기록(localStorage)의 키입니다 |
| 표제어 | 카드의 정체 |
| 표제어변형 | 한자·외국어 등 원어 표기 (없으면 빈 값) |
| 축1~축4 | 이 카드가 물릴 수 있는 출제 각도. `라벨: 내용` 형식. **축1만 필수** |
| 캡션 | 작품 카드 전용. 작가·제목·연도 |
| 이미지링크 | 도판 URL (없으면 빈 값) |
| 중요도 | 1~4 등급 (1이 최상). 추후 `출처` 개수 기반 빈출도로 교체 예정 |
| 과목 | 일반교육학 / 미술교육학 / 서양미술사 / 동양미술사 / 한국미술사 / 표현기법 |
| 유형 | 기법 / 인물 / 작품 / 사조 / 원리 / 개념 / 교육과정 |
| 시대 | 해당 없으면 빈 값 |
| 태그 | 세미콜론(;) 구분 다중값 |
| 출처 | 기출 출처 `연도+과목+문항`. 예: `2024A9;2022A3` |

> 쉼표가 들어가는 값은 `"..."` 로 감싸면 됩니다.
> 축 라벨은 12자 이내여야 배지로 표시되고, 콜론이 없으면 본문으로만 렌더됩니다.
> 자세한 설계 근거와 유형별 권장 라벨은 [기획.md](기획.md) 참조.

관계는 카드가 아니라 **`data/links.csv`**(출발·관계·도착·메모)에 둡니다. 한 행이 양방향으로
동작하며, 관계 종류가 늘어도 카드 스키마는 그대로입니다. 자세한 내용은 [기획.md](기획.md) 참조.

백업: `data/cards.backup-v1.csv`(설명 단일 컬럼 시절), `data/cards.backup-v2.csv`(짝 컬럼 폐지 직전).

## 로컬 실행

브라우저가 `file://` 에서 CSV fetch를 막으므로 간이 서버로 실행합니다.

```bash
python -m http.server 8123
# http://localhost:8123
```
